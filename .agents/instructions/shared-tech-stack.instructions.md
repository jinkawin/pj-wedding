# Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 3
- **State**: Jotai
- **Forms**: React Hook Form + Yup validation
- **i18n**: react-i18next with next-i18next
- **HTTP**: Axios
- **Testing**: Vitest + Testing Library
- **Package Manager**: Yarn 4 (Always use `yarn` commands for package management, running scripts, and builds)
